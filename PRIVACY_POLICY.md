# Politique de confidentialité

Cette application est destinée à un usage privé et personnel.

## Collecte de données
L’application peut utiliser Firebase (Authentication et Firestore) afin de permettre la connexion de l’utilisateur et le stockage de données liées à l’application.
Aucune donnée personnelle n’est collectée à des fins commerciales.

## Partage des données
Les données ne sont partagées avec aucun tiers.

## Public concerné
Cette application ne cible pas les enfants de moins de 13 ans.

## Contact
Pour toute question concernant cette politique de confidentialité, vous pouvez contacter le développeur via le dépôt GitHub du projet.
